VectorZ portable mode

While this file sits next to vectorz.exe, VectorZ keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the VectorZData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move VectorZ with its
settings. The first time VectorZData is created, any settings already in
%APPDATA%\VectorZ are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders VectorZ loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\VectorZ) instead.
If VectorZData can't be written (for example on a read-only drive), VectorZ logs a
warning and uses %APPDATA%\VectorZ instead.
